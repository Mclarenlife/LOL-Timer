# RIFT TIMER · 召唤师技能计时

一个本地运行的英雄联盟辅助网站，记录敌方上单、打野、中单、射手、辅助的召唤师技能冷却。原生 HTML / CSS / JavaScript，无依赖、无账号、无构建步骤。

## 打开网站

最简单的方式：双击 `index.html`。

推荐使用本地服务器（需要 Node.js）：在项目目录运行 `node server.cjs`（或 `npm start`），打开 http://127.0.0.1:4317 。也可双击 `启动网站.cmd`，启动成功后会自动打开浏览器。

直接打开文件时，浏览器对本地存储和音频的支持可能不同。使用本地服务器可得到更一致的体验。不要在两种打开方式间切换以恢复同一局计时，因为它们使用不同的存储空间。

## 使用

点击「对局码设置」创建或加入对局，输入 6 至 32 位数字，前导零有效。创建时上传技能、当前计时和提醒偏好。队友可修改同一面板，每秒同步一次。点击时间旁的箭头可扣减 5、10 或 20 秒，空闲技能会从扣减后的时间开始计时。结束后自动显示基础冷却。

创建和加入对局都只需输入 6–32 位数字。正式站使用同源对局服务，GitHub Pages 会自动转到正式站。本地预览默认连接同一服务，可通过 RIFT_ROOM_API 覆盖部署地址。

- 每个位置有两个技能槽，点击技能名称可更换技能。同一个位置不能选择重复技能。
- 点击「开始计时」按所选技能的默认冷却倒计时。运行中按钮锁定，防止重复点击覆盖时间。
- 右侧重置按钮清除单个计时；「重置本局」经确认后清除全部计时和提醒记录，保留技能及设置。
- 全局设置：结束时、提前 30 秒、提前 1 分钟或自定义 0–600 秒提醒；可开启提示音和中文语音。
- 每轮计时提醒一次，提前提醒后不在结束时重复提醒。提前量大于等于冷却时间时立即提醒。改变设置只影响尚未提醒的计时。
- 「试听提醒」使用尚未保存的声音选项，取消设置不改变已保存偏好。
- 技能、提醒偏好、倒计时截止时间和已提醒标记保存在浏览器 localStorage；刷新后按真实经过时间继续计时。最近提醒记录仅保留当前页面会话，最多 30 条。
- 必须保持网页打开才能提醒。浏览器后台节流、休眠、设备静音可能延迟或阻止声音；回到页面后会根据真实截止时间更新，不会慢慢补秒。关闭页面后不会在后台运行。

## 冷却数据与范围

数据版本：Riot Data Dragon **16.23.1**，获取日期 2026-11-18。

| 技能 | 秒 |
| --- | ---: |
| 闪现 | 300 |
| 传送（基础形态） | 300 |
| 引燃 | 180 |
| 惩戒（两次施放间隔） | 15 |
| 治疗术 | 240 |
| 屏障 | 180 |
| 虚弱 | 240 |
| 净化 | 240 |
| 幽灵疾步 | 240 |

每路可配置明朗之靴（+10）或猩红明朗（+20），并叠加星界洞悉（+18）。启封的秘籍仅改变置换节奏。实际冷却 = 基础冷却 × 100 ÷（100 + 总急速）。修改进行中的计时保留已过时间；惩戒保持 15 秒施放间隔。设置中的记录时自动扣秒在每次新开表时生效。传送沿用基础形态。应用按请求使用基础默认冷却，属于手动记录工具，不读取游戏状态。

官方数据：https://ddragon.leagueoflegends.com/cdn/16.23.1/data/zh_CN/summoner.json

技能图标来自 Riot Data Dragon；位置图标来自 CommunityDragon。所有运行资产均保存在 `assets/lol/`，页面不依赖外部 CDN。更新数据时同步修改 `timer-engine.js`、数据说明与快照。

## 验证

运行 `node --test tests/timer-engine.test.cjs`（或 `npm test`）：验证官方冷却数据一致性、计时独立性、时间漂移与刷新恢复、提醒阈值和只触发一次、切换技能、重置、非法存储数据。

运行 `npm run check`：JavaScript 语法检查。

## 文件结构

- `index.html`：主界面与弹窗
- `styles.css`：设计系统及响应式布局
- `timer-engine.js`：纯计时状态逻辑
- `app.js`：交互、渲染、本地存储、声音和提醒
- `server.cjs`：零依赖本地服务器，默认仅监听 127.0.0.1
- `tests/timer-engine.test.cjs`：计时行为测试
- `brand-spec.md`：设计与素材来源

设计参考 [ConardLi/garden-skills 的 web-design-engineer](https://github.com/ConardLi/garden-skills/blob/main/skills/web-design-engineer/SKILL.md)。项目独立制作，与 Riot Games 无隶属关系；英雄联盟及其素材的相关权利归 Riot Games 所有。

## 语音口令

点「开启语音」，允许麦克风后说“上单闪现”“打野惩戒”或“中路点燃”。浏览器首次按需下载约 42 MB 的中文模型，在本机处理麦克风音频。仅最终识别到的、已配置的技能会开始计时；运行中的计时保持原截止时间。再次点按钮或关闭页面可停止监听。

HTTPS 页面与 localhost 可以直接使用麦克风。在线 HTTP 对局页会打开本站 GitHub Pages 的 HTTPS 麦克风窗口，需要在该窗口点一次「开启麦克风」，并保持两个窗口打开。两个窗口只交换识别到的指令和运行状态。

识别引擎使用 [vosk-browser](https://github.com/ccoreilly/vosk-browser)，模型为 [Vosk small-cn-0.22](https://alphacephei.com/vosk/models)。
