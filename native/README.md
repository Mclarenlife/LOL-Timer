# Rift Timer

Android 和 Windows 的英雄联盟召唤师技能计时工具。两端共用 Java 计时模型与对局协议，Android 界面使用系统 Activity 和控件，Windows 界面使用 Swing，发布包自带 Windows x64 运行时。

## 安装和启动

- Android 8.0 及以上系统可安装 `release/RiftTimer-Android.apk`。安装完成后从应用列表打开 Rift Timer。
- Windows x64 可直接运行 `release/windows/RiftTimer/RiftTimer.exe`。分发时可使用 `release/RiftTimer-Windows-x64.zip`，完整解压后运行其中的 EXE。
- 各位置的两个技能可以独立更换。点击「计时」按技能默认时间开始，点击箭头可以扣减 5、10 或 20 秒。空闲时扣秒会直接开始该次计时，结束后恢复默认时长。惩戒按网站规则记录两次施放间隔 15 秒。

## 提醒和多人对局

提醒设置支持 0–600 秒。填 0 表示结束时提醒，填 60 表示提前一分钟提醒。语音使用设备已安装的中文语音引擎。Windows 可以勾选「置顶」。Android 可在提醒设置内开启「本机后台提醒」，允许通知后，应用通过前台服务继续跟踪计时。强行停止应用或系统限制运行可能中断提醒。

单人模式会保存技能、截止时间和设置。创建对局时输入自选的 6–32 位数字，并上传当前单人配置；队友可以在 Android、Windows 或原网站输入相同对局码加入。在线修改通过原网站的 HTTP 对局接口保存，客户端约每秒刷新一次。两名玩家同时更改时，服务器会拒绝过时的提交并提示重试。离开对局会恢复各自的单人配置。提醒设置在对局内共享，后台运行和窗口置顶由本机控制。

## 构建

在 Windows 中安装 JDK 17 或 21（含 jpackage），Android SDK Platform 35 与 Build Tools 35.0.0，设置 JAVA_HOME 和 ANDROID_HOME。PowerShell 中运行 `.\build.ps1`，或指定 `-Target android`、`-Target windows`。安装了 Android SDK Platform 36 时可加 `-Platform android-36`。依赖的 Gson 2.10.1 已放在 lib 中。

- shared/rift 包含计时、存储结构和服务端同步逻辑。
- android/rift 和 android/res 包含安卓界面、通知、系统服务和资源。
- windows/rift 包含桌面界面。Windows 状态保存在本机 LocalAppData 下的 RiftTimer/state.json。
- tests/rift/Check.java 包含单人回归检查。加参数 rooms 时，会在已配置的服务创建单独的测试对局，验证跨客户端读写。
- art 包含原网站使用的 Riot Games 技能与位置图标。此工具为非官方项目。
- .signing 保存这份 APK 的签名密钥及本机构建密码，应私下备份，后续覆盖安装需要相同签名。该目录已加入 Git 忽略列表。


## 2.0 语音与悬浮窗

两端点击「开启语音」后可连续说出“位置 + 技能”，如“上单闪现”“中路点燃”“下路治疗”。技能必须已配置在该位置。冷却中的技能保留原截止时间。应用使用内置 Vosk 中文小模型在本机解码，麦克风音频不进入对局服务。安卓离开前台时结束语音监听，后台计时提醒仍按原设置运行。

Windows 主界面的「悬浮窗」可单独开关。拖动窗口移动，拖动右下角斜线缩放，位置与尺寸自动保存。「设置」中可修改不透明度、锁定或解锁。右上角的锁可随时切换状态，锁定后其余区域鼠标穿透。解锁后可点击技能计时、右击扣秒或重置、点击位置设置急速。主窗口顶栏「说明」提供完整操作指南。桌面合成器控制普通置顶窗口的显示，独占全屏可能遮住它。悬浮窗只使用本程序的窗口句柄，数据来自本工具的手动记录、语音口令和对局服务。

腾讯协议限制未经授权挂接游戏数据及修改游戏指令，Riot 开发规范限制带来不公平优势的信息。公开资料未确认国服对本产品的认可。参见[腾讯游戏许可及服务协议](https://game.qq.com/contract.shtml)与[Riot 游戏完整性规范](https://developer.riotgames.com/docs/lol#game-integrity)。

离线识别引擎及模型来自 [Vosk](https://alphacephei.com/vosk/models)，型号为 vosk-model-small-cn-0.22（Apache-2.0）。Windows 使用 Vosk 0.3.45，Android 使用 Vosk 0.3.47；JNA 为 5.17.0。构建所需的库和模型已随项目保存在 lib 和 voice-data 目录。

## 2.1 计时和语音控制

位置旁的「急速」设置只影响该位置。按 16.23.1 官方数据，明朗之靴 +10、猩红明朗 +20（二选一）、星界洞悉 +18。启封的秘籍记录置换能力，直接急速为 0。实际冷却毫秒为基础毫秒 × 100 ÷ (100 + 总急速)，四舍五入到毫秒，界面剩余秒数向上取整。修正已启动计时的装备时保留已过去的时间。惩戒追踪固定 15 秒施放间隔。记录时自动扣秒支持 0–300 秒，仅在每次新开表时执行一次，最短归零。

Windows 设置可开启到期行闪烁（三秒），并在「语音输入」选择录音设备、随时说话、长按或按键切换模式。保存后在主界面开启语音。默认快捷键 F8。点击「录入快捷键」，直接按下键盘按键、组合键或鼠标侧键，选择后自动保存，重新打开时会显示上次选择的模式。按键模式在待命时预载模型，仅在开启发言时打开所选录音设备；顶部「语音交流中」表示本机正在识别口令。录音设备及快捷键保存在本机。
